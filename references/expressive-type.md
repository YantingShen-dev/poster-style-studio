# 特殊字形：先参数化，再选择轮廓替代

当参考海报的标题具有明显的像素、柔性、几何拼搭或其他定制字形时读取本文件。普通正文仍用可编辑文字。先判断字形能否由规则生成，不因为找不到同名字体就直接描摹或换相似字体。

## 判断与试作

观察笔画、转角、端点、粗细、字腔、连接、基线及重复结构，区分字形结构与表面纹理。选择能解释参考特征的技术路线，先用原稿中的代表字符和一段替换文字试作。默认参数应接近原稿；改字后仍要保持同一套造型规律。

以下是候选方法，不是每套工具都要提供的效果清单：

| 观察到的特征 | 可尝试的生成方法 | 对应的用户参数 |
| --- | --- | --- |
| 像素、点阵、阶梯边缘 | 对基础字形轮廓或字形遮罩作网格采样，按覆盖率生成矢量方块／圆点；用阈值或轮廓偏移调节笔画 | 像素尺寸／颗粒度、点间距、点形、笔画粗细；字号和像素尺寸分开控制 |
| 柔软、圆润、膨胀、融接 | 从合适的字形骨架或轮廓出发，尝试圆角、曲线平滑、轮廓膨胀与收缩，或距离场阈值后提取轮廓 | 柔软程度、圆角程度、膨胀量、连接程度；选择确实匹配原稿的参数 |
| 模块化、切口、拼接字 | 用重复几何部件与笔画规则组成字形，或对基础轮廓做可控切割和替换 | 模块尺寸、切口大小、连接宽度、倾斜程度 |
| 弯曲、波动、弹性字 | 基于字形轮廓或骨架施加连续形变，控制振幅、频率及曲率，再生成可导出的几何 | 弯曲程度、波动幅度、节奏；带随机变化时保留种子 |

“柔软”不能直接等同于模糊滤镜，“像素化”不能只是在屏幕上降低整张海报清晰度。参数必须实际驱动字形变化，且变化方向能被用户理解。尝试失败时记录具体失真，例如字腔消失、笔画粘连、细节变形或替换文字无法生成；不要把未尝试说成技术上不可能。

优先使用已有合适字体作为文字输入与字形覆盖的基础，再做结构处理；模块字也可使用明确的字符规则。只重建原稿几个字符，不等于生成了可输入任意文字的字体。明确支持的字符范围；不支持的字符应提示或显示明确替代，不得静默丢字。中文不能由几个原稿字推定已覆盖整套字符集。

## 沟通与控件

先给出有依据的方案，再问会影响使用方式的选择，例如是否需要改中文标题、希望像素颗粒能变化到什么程度。用户已经要求参数化时直接执行；技术路线由 Agent 判断，不把算法选择交给用户。像素或柔性是条件触发，不给所有风格堆同一套滑块。

提供原文输入、必要的字形参数和还原到参考样式的操作。参数名称使用设计语言，给出可用范围、步长与接近原稿的默认值。字号负责文字尺寸，字形参数负责造型；拖动文字框依然只改排版区域。多段特殊标题分别拥有自己的文本、参数和样式状态；修改一段不能同步覆盖其他标题，除非用户明确要求联动。

## 工程实现与接力

按 [风格扩展](style-extension.md) 接入实际生成器。底座没有通用特殊字体算法，必须为当前参考实现并验证，不能仅添加这些说明或没有效果的控件就宣称完成。

保留原始字符串、基础字体资源／字符规则、字号与排版信息、字形参数、种子、模块版本，以及当前生成的矢量轮廓。每段标题使用独立实例 ID；例如在 `style.params[moduleId].instances[instanceId]` 中保存参数，并通过稳定 `generatorKey` 关联生成对象，不能让多个标题共用一份可变参数。

优先输出标准路径／几何对象；网格采样可用临时位图作计算中间态，最终逐字归组或合并路径，避免把数千颗粒暴露为顶层图层。保存实际字体资源，不仅保存字体名称。重生成只更新该标题的几何，保留用户布局、其他标题和新增对象；一次参数修改可撤销。手动改节点与重生成可能冲突时，提供明确的“转为静态轮廓”操作，不能悄悄覆盖节点修改。

预览、静态导出和重新打开工程使用同一套参数与生成结果；不能只用浏览器临时 CSS 效果。缺少生成模块时，存档轮廓仍可显示和做基础编辑，但要说明已无法改字生成。

## 无法较好参数化时的双版本替代

只有试作无法同时满足原稿特征、可读性和所需改字范围时，才使用以下组合，并简要说明参数化方案的具体不足：

1. **原稿轮廓版**：用类似钢笔的贝塞尔路径描摹字符，保留字腔、曲线、位置和字距，以忠实还原原稿为目标。它是固定字符的矢量几何，不能通过输入文字换字；仍可移动、配色和编辑路径，不称为可输入的字体。
2. **可改字字体版**：提供形态相近且覆盖所需字符的真实字体及文字对象，优先内嵌可分发的 TTF／OTF，也可使用受支持的 WOFF／WOFF2。这里是字体文件，不是 TIFF 位图。字体不可用或无法随工程提供时说明替代及缺失，不能只列出一个字体名称却声称已交付。

两版并存，明确标为“原稿轮廓／可改字”，切换时只显示选用版本；不自动覆盖另一版的文字或造型修改。字体版的形态差异需要说明。切换选择、隐藏内容及字体资源均随工程保存。参数化已可用时，不必再强制增加双版本。

## 验收

- 对照原稿检查默认字形，改变参数的低、中、高值，确认造型实际变化且字腔、笔画和可读性正常。
- 替换为范围内的新文字，包含不同长度、大小写及所需中文；不支持的字符有明确反馈。不能只测试原稿标题。
- 同时放置两段标题，修改其中一段的内容和参数，另一段保持原样；检查撤销、字号与框尺寸行为。
- 保存工程，在干净环境打开后继续改字和调参；检查字体资源、生成参数、轮廓、PNG 与 SVG 输出一致。
- 使用双版本替代时，验证轮廓还原、字体版改字、切换及保存恢复；不得将静态轮廓描述为任意字符生成器。
