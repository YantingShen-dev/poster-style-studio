# 读图与必要沟通

## 先观察，再提出工具方案

记录画布比例、标题／正文／补充信息层级、配色、字体形态、图形语法、主体和背景关系、重复对象、纹理和空间疏密。区分“已观察”“推测”“需要用户补充”。识别不清的日期、姓名与重要活动信息不能编造。

说明最值得保留的 3–5 个特征，以及哪些内容未来会变化。形成简单对象清单：对象名称、表达方式、开放操作、是否复用、重建置信度。它是构建输入，不要求用户填写技术表格。

选择表达方式：文字保持可输入；规则几何用矢量；曲线用可编辑路径；重复纹样用生成器；照片和复杂纹理按需要嵌入。被遮挡内容不是“提取”就能获得，必要时重绘或询问。

## 触发规则

| 信号 | 合适的问题 | 影响 |
| --- | --- | --- |
| 重复角色／图标／小物件 | 是否把它们作为可重复拖入的贴纸？推荐保留已有元素。 | 素材库及实例；扩展新动作需要额外决定 |
| 点阵／波纹／放射结构 | 是否加入动态变化与逐帧导出，还是保持静态？ | 动画模块；静态图不能证明原设计的运动方式 |
| 主题照片可能替换 | 后续是否需要换照片并继续用这套处理方式？ | 参数生成或固定素材 |
| 像素、柔性等特殊标题字形 | 先按[特殊字形流程](expressive-type.md)判断并试作参数化；再沟通必要的改字范围及造型调节需求。无法较好参数化时，说明轮廓版＋相似字体版的替代方案。 | 优先可调字形生成器；双版本是后备方案 |
| 复杂主图难以拆开 | 哪些部分必须单独编辑？推荐先保留复杂图像、拆开文字和几何。 | 重建粒度及保真边界 |
| 系列用途尚不明确 | 后续主要改活动信息、主题素材，还是多个版幅？ | 首批预设与布局 |

这张表是**读图后必须执行的触发检查**，不是可略过的提示。特别是特殊字体和动效：看见非普通字体时，问用户更看重原稿轮廓、可改字范围，还是可调的字体颗粒／柔性参数；看见适合运动的重复图案或用户提到动态时，问是否启用以及具体运动、逐帧 PNG 是否必要。可把相关信号合并成 1–3 个问题，使用工具提问或普通对话都可以。已知信息不重问，无相关信号不硬问。未答复时先完成不依赖答案的底座；过了合理回应时间仍无答复，说明采用的可逆默认及后续如何切换。静态重建不等于用户拒绝动效。

## 从判断到界面

用户面对“添加贴纸”“点阵密度”“标题字形”等设计概念，而非渲染 API、节点编码和模块版本。一般用户看到必要的控制项；复杂外观与节点编辑可折叠，不能因此不实现。

调整版幅默认不拉伸原对象。需要整体缩放或重新排版时明确操作方式，不能悄悄改变所有位置。

素材库、动态效果和专属图形都必须与通用图层、选择、历史记录、工程保存协同。改变参数时保留用户添加的文字、对象与合理的人工布局。
