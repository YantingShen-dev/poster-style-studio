# 风格扩展

扩展源文件为 `assets/editor/style.js`。基础发行版不预置任何具体海报风格。将项目专属实现写入构建输出源码中的该文件，使用 `--source` 重新打包；不要修改通用模型来硬编码某张参考图。

在 `window.PosterStyleModules` 注册 `{id,version,label,controls,generate}`。`controls` 为数据化字段：`key,label,type,min,max,step,options,default`；type 支持 number、color、select、checkbox、text；text 可设置 maxLength。`generate({project,params,seed})` 返回通过 `PosterCore.createObject` 构建的标准对象数组；对象需具有稳定的 `generatorKey`。无论是专属标题、图案、贴纸还是导入位图，实例都进入 `project.objects`，具备同一套 `m/w/h`、图层、外观与效果属性，能单独选择、拖动、缩放、旋转、保存和导出。参数控制只改变标准对象的生成输入；不要另外创建无法由通用工具操作的图层或悬浮 DOM。模块不直接操作编辑器历史或下载文件。

编辑器设置中加载已注册模块，更新参数经一次事务生成并校验新工程。用户增加的对象保留；相同 `generatorKey` 复用 ID 及人工修改的变换，生成几何可以更新。首次生成以模块默认坐标放置。模块应使用传入 seed 实现确定随机，不用当前时间作为隐藏随机源。

复杂参数面板可以扩展 `editor.js`，但须沿用工程中的 `style.params` 和通用事务。驱动照片放在 assets，不保存在闭包里。若效果需要专门的绘制逻辑，应优先输出基础矢量；可编辑特殊对象的引入须同时实现校验、历史、渲染、导出、恢复及模块版本处理。

特殊标题的生成方案按 [特殊字形与参数化](expressive-type.md) 选择；每段标题保留独立的字符串、参数、资源和实例标识，不能共享一份可变样式状态。重生成同时保留既有对象的 `editorState`，不重置该对象的比例选择和属性分组展开状态。

贴纸通过 `style.stickers` 存储对象组合，复用项目 assets。侧栏自动用贴纸对象生成 SVG 缩略图，以紧凑卡片展示；保存贴纸时应包含能辨认造型的对象，而非仅保存名称。全画布纸纹等覆盖对象应设置 `locked:true, hitTest:false`，避免挡住下方可编辑内容。生成贴纸的来源可能是裁切提取、矢量重绘或重新生成；在不确定时说明来源，不把重画当成精确提取。

## 可选动效

只有用户选择后启用 `animation.enabled`。基础呼吸模块对指定对象做周期缩放，提供幅度、时长、帧率、暂停、拖动选帧及 PNG 序列 ZIP。若用户选择的是点阵半径呼吸或走线生长，需要写对应模块与确定采样逻辑，不能用整组缩放替代而不说明。

预览和导出共用同一个时间参数。导出 t=i/fps，i 从 0 到 round(duration*fps)-1；终点不重复第一帧。渲染完成后再采下一帧，ZIP 内保存帧序及参数清单。限制一次导出的尺寸和总帧数，并展示估算，避免无提示耗尽内存。

缺少匹配模块时保留存档几何并显示提示，生成面板不提供会清空内容的假按钮。兼容性依赖工具模块版本，工程文件不会自动下载模块。
