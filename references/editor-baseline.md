# 默认能力与行为约定

用户未缩小范围时，每次生成工具都具有下列能力。读源代码和测试理解底座；不要只保留相似外观。

| 模块 | 要求 |
| --- | --- |
| 工程 | 新建、保存／另存、打开、手动恢复本机草稿；工程名称与明确保存反馈 |
| 图层 | 重命名、多选、排序、显隐、锁定、分组／解组、复制、删除；层级关系保存 |
| 视图 | 缩放、适应、100%、平移；视图缩放与对象缩放不混淆 |
| 画布 | 自定义宽高、比例预设、背景色／透明；调整边界不默认拉伸内容 |
| 变换 | 移动、尺寸、等比缩放、旋转、翻转、斜切、四角透视、多选整体变换 |
| 对齐 | 拖动边缘／中心吸附、辅助线、等距提示；显式对齐与分布 |
| 文字 | 内容、字体、字号、字重、斜体、字距、行距、对齐、多行文本框 |
| 图形 | 矩形、椭圆、线、多边形、星形、独立可编辑路径 |
| 钢笔 | 点击直线点、拖拽曲线点、开放／闭合；完成后增删节点及控制柄调整 |
| 外观 | 纯色／线形、放射形、角度渐变／PNG、JPG 平铺图案；渐变色带支持多个颜色节点的新增、拖动、改色、定位、删除及模板保存；方向与反向、图案比例与旋转；描边、线宽、端点、连接、透明度、投影、发光、常用图层混合模式；每个对象独立保存 |
| 图片 | 上传、替换、等比显示、裁切、可见像素边缘描边、透明度；工程内嵌素材 |
| 恢复 | 撤销／重做；一次拖动合并为一次；输入框内保留正常文字快捷键 |
| 导出 | PNG、JPG、SVG、PDF；导出尺寸和背景选项；不含选框与辅助线 |

工具栏把保存和打开放在显眼位置。拖入一个工程不覆盖当前工作，除非载入与校验成功。选中对象后属性对应真实类型；图片不出现无意义的填充设置。

## 工作区与操作习惯

- 左侧使用紧凑的图标工具栏：选择、手形、钢笔、节点、文字与基本图形；悬停显示名称和快捷键，当前工具有选中状态。钢笔是独立工具，路径命令仅在钢笔或节点模式出现。
- 选择图形工具后，在画布拖拽确定位置和尺寸；点击放置默认尺寸。文字创建后直接进入内容输入。Shift 约束正方形、正圆及线条角度；完成后返回选择工具。
- 空白区域从左向右拖拽为完整框选（蓝色实线），从右向左为触碰框选（绿色虚线）；Shift 追加选择。以实际轮廓判断，不把椭圆或三角形外接框的空角当作图形。框选不包含阴影、发光及描边外溢。
- 画布点击须穿透锁定对象与 `hitTest:false` 的装饰对象，继续命中下方可编辑对象；锁定层仍可在图层面板选中。全画布纹理、颗粒、滤镜覆盖层在初始工程中标为 `hitTest:false`，不让它们拦截画布操作。
- 有无填充都保留几何内部的点击区域；三个及以上节点的开放路径也可从内部选中。此命中区域只存在于编辑器，不进入作品导出。选框提供八个缩放手柄，旋转位置显示箭头图标与旋转光标。单选对齐画布，多选对齐选区，三个以上对象支持等距分布。
- 左右侧栏通过分隔线拖动调宽；分隔线聚焦后方向键调整，不影响画布对象。图层面板可拖动标题浮动，靠近左右侧栏显示停靠区域，也可点击停靠按钮。图层面板底边可上下拖动调高，浮动和停靠时均有效并记住高度。右上角“恢复视图”将画布居中并适应窗口；“画布大小”弹窗设置尺寸、预设与背景，新建默认透明。
- 图层面板顶部只提供打组、解组、新建图层图标；右下角固定放置删除和蒙版按钮。蒙版使用单一切换按钮，启用时高亮，再点一次解除，不设独立解除按钮。父子层级通过拖拽调整。图层文件夹使用 `group` 对象，可嵌套。拖到行边缘排序，拖到文件夹中部移入，拖到顶层区域移出；必须显示落点提示并保持对象世界坐标。禁止拖到自己或后代中。双击名称重命名，组合可折叠，图层列表 Shift 连续选择，Ctrl/Command 切换选择。
- 向下蒙版：上方图片或内容使用下方闭合形状裁剪。单选时采用紧邻下方兄弟；也可选择同父级的两对象。支持矩形、椭圆、多边形、星形和至少三个节点的闭合钢笔路径。建立带 `maskId` 的组，保留原图、路径与变换；通过图层选中图片移动，选中蒙版路径并按 N 编辑节点。解除后恢复独立对象，可撤销。隐藏蒙版形状会隐藏裁剪结果。这里是矢量轮廓裁剪，不是灰度画笔蒙版。
- 普通滚轮平移，Ctrl/Command + 滚轮以指针为中心缩放。空格临时切换手形，释放后恢复；也支持 H 手形与中键平移。底部常驻快捷提示，问号入口打开速查。
- 工作区布局保存在本机，与 `.posterproj` 内容分离。侧栏调宽、停靠和视图平移不进入作品历史，不会使工程变脏。

风格贴纸在左侧以紧凑缩略图卡片排列，缩略图从贴纸自身的对象生成，保留颜色、轮廓和透明背景；名称只作辅助识别。点击卡片插入独立可编辑副本。

这些约定用于所有风格；参考图改变初始作品、贴纸和生成参数时，保留工具位置与常用交互。专属控件放在风格参数区，避免挤占基础操作。

交互依据：[Figma 工具说明](https://help.figma.com/hc/en-us/articles/360041064174-Access-design-tools-from-the-toolbar)、[Figma 对象选择](https://help.figma.com/hc/en-us/articles/360040449873-Select-layers-and-objects)、[Photoshop 浮动面板](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/stack-floating-panels.html)。底座提供上述明确实现的能力，不承诺复刻完整专业软件。

图层锁定影响画布变换与选择，属性面板可明确解锁。多选默认选择同一层级对象；跨层级操作先给可执行提示。组合变换不损害子对象的文字、路径与素材身份。

底座使用 SVG 对象与矩阵变换，位图仅用于图片资源。文本框依照字体度量换行；字体替代会改变排版，因此交接检查字体是否可用。内嵌字体通过项目资源注册。

PDF 使用浏览器打印当前作品。提供画布比例页设置及取消页眉页脚说明；浏览器可能针对滤镜进行局部栅格化，不能声称任意对象都保持全矢量。PNG/JPG 用同一 SVG 画面栅格化。JPG 不支持透明，默认填充白色。

首次运行底座是空白工具。Agent 必须用用户参考图构建初始工程，并在运行界面检查完成度。不要把底座默认主题当作用户海报的风格。
### 画布文字与字体菜单

- 双击文字框内部直接原位编辑，包括文字之间和框内空白。支持多行、中文输入法和普通文本粘贴；Ctrl/Command+Enter 或点击外部完成，Esc 取消，输入法组字期间不截获确认／取消键。
- 文字框的八个手柄默认独立调整宽高与长宽比，沿自身旋转方向拉伸，固定对侧边角并重新换行。文字本身的尺寸和字形不随框缩放；只有字号控件改变字体大小。右侧宽高输入遵循同一规则。Shift 或“锁定文字框比例”仅约束框的比例。缩放多选或组时也保留其中每段文字的实际字形尺寸，通过框尺寸重新排版。
- 原位编辑遵循对象及父级的世界变换；锁定对象或父组不能进入编辑。一次完成对应一次撤销，编辑未完成时保存工程也必须包含最新文字。
- 字体菜单分组展示中文、英文和工程内嵌字体，并保留不在预设中的当前字体。默认提供 32 个中文、35 个英文常用选项；检测本机可用状态，缺失时明确提示安装或导入。不得把字体名称列表描述成已打包的字体文件。

- 属性面板属于当前元素：每个对象按自身 ID 独立记住等比缩放和投影、发光、填充等分组展开状态，随工程与草稿保存；不能按全局或对象类型共用。多选整体缩放使用独立的临时选区状态，不覆盖各元素设置。填充、描边、透明度、投影、发光、字体字号及变换值始终取自选中对象；单选修改不影响其他对象。编辑属性时保持焦点、Tab 顺序与滚动位置，撤销造型修改不重置分组展开。
- 双击画布中的组进入内部编辑，组外内容淡化且不可从画布误选；嵌套组可逐级进入，Esc 或“退出组”返回上一级。淡化仅用于编辑视图，不改变对象透明度或导出。
- 选中元素后方向键移动 1 个画布单位，Shift 加速为 10；与视图缩放无关，可撤销。输入文字或修改数字时保留输入控件自身键盘行为。
- 画布对象右键提供复制、剪切、粘贴、打组／解组、水平／垂直翻转、斜切和透视；多选时可打组，单选普通组合时可解组。右侧水平／垂直翻转下方也提供斜切和透视。斜切拖动边中点，透视拖动四角；Esc 退出变换编辑，几何仍可再次进入修改。透视预览与作品导出不应出现内部网格接缝，只显示实际作品轮廓。变换写入对象工程数据，适用于图片和基础图形，不将对象拍平成位图。
- Ctrl/Command+C 复制当前选中对象及子图层，Ctrl/Command+V 在偏移位置粘贴，Ctrl/Command+Shift+V 原位粘贴；对象引用、蒙版与嵌入图片资源随复制内容保留。文字输入框内仍执行正常文本复制粘贴。
